# Optional brand ending

Use a brand ending only when requested. Keep it separate from the fit/readiness conclusion so the editorial judgment does not look like a product advertisement.

Default personal brand when specified by the user:

- Name: `Acemode`
- Slogan: `10X Faster. Log off earlier.`
- Supporting Chinese line: `把时间留给更重要的事`

Correct spelling in the delivered asset unless the user explicitly requires a legacy spelling. Keep the brand card to roughly 3–4 seconds. Use a distinct full-frame background, restrained brand glow, and character or word-level bounce. Do not place factual product claims on the brand card.

Make brand fields configurable in `story.json`; do not hardcode Acemode when another project or user requests different branding.
